About this course

This course covers the foundations of building for the web — HTML, CSS, and JavaScript through to client-server interaction, APIs, and modern front-end practice. It runs jointly for students at Gachon University and the Jizzakh branch of the National University of Uzbekistan, with shared materials and a common repository so both cohorts work from the same source.

Everything above is a live folder — updates land here first. If you're enrolled, star or watch the repository to catch new material as it's added.
