Concept

What is React?

  • A JavaScript library for building user interfaces ??made by Facebook/Meta in 2013
  • Breaks your UI into small, reusable pieces called components ??like LEGO bricks
  • When data changes, React automatically updates only the changed parts of the page ??no manual DOM work
  • Used by Netflix, Airbnb, Twitter, Instagram, Khan Academy, Coursera, Figma??/div>

?뵎 Key idea: Instead of writing one big HTML file, you build small components and compose them like building blocks.

Concept

JSX ??HTML inside JavaScript

??Old way (plain DOM)
const el = document.createElement('div');
el.className = 'card';
const h2 = document.createElement('h2');
h2.textContent = 'Hello Alice';
el.appendChild(h2);
document.body.appendChild(el);
// Very verbose ??6 lines for a <div><h2>
??New way (React JSX)
function Card() {
  return (
    <div className="card">
      <h2>Hello Alice</h2>
    </div>
  );
}
// Looks like HTML ??easy to read!

?좑툘 JSX looks like HTML but isn't. Notice: className not class. JSX is compiled to React.createElement() calls by a tool called Babel automatically.

Code

Your First Component

A component = a function that returns JSX
// Step 1: Define the component
function Welcome() {
  return (
    <div>
      <h1>Hello, World!</h1>
      <p>My first React component!</p>
    </div>
  );
}

// Step 2: Use it like an HTML tag
function App() {
  return <Welcome />;
}
4 rules to remember:
  • Capital Letter start: Welcome not welcome
  • Returns one root element (wrap siblings)
  • Use className not class
  • JavaScript goes in { curly braces }
Output in browser:
Hello, World!
My first React component!

Concept

Props ??Passing Data to Components

Props in action:
// Define: accept props as parameter
function Greeting({ name, age }) {
  return (
    <div>
      <h2>Hello, {name}!</h2>
      <p>Age: {age}</p>
    </div>
  );
}

// Use: pass props like HTML attributes
<Greeting name="Alice" age={20} />
<Greeting name="Bob"   age={22} />
// Same component, different data!
Props flow ONE WAY: Parent ??Child
