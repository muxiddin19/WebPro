React Effects — useEffect Hook

useEffect lets you synchronize a component with an external system — fetching data from an API, subscribing to a WebSocket, setting up a timer, or directly manipulating the DOM. It runs after the component renders.

1. What is a Side Effect?

React components should be pure functions — given the same input (props + state), they always return the same JSX. A side effect is anything that reaches outside this pure render: network requests, timers, subscriptions, logging, or direct DOM mutations.

  • OK inside render: Calculating derived values, filtering lists, formatting strings
  • Must use useEffect: fetch(), setTimeout(), addEventListener(), WebSocket connections, document.title
⚠️

Never put side effects directly in the render body. They would run on every render, causing infinite loops, duplicate requests, and unpredictable bugs.

2. useEffect Syntax & Dependency Array

import { useState, useEffect } from 'react';

useEffect(
  () => {
    // Effect code runs here (after render)
    console.log('Effect ran!');

    // Optional: return a cleanup function
    return () => {
      console.log('Cleanup!');
    };
  },
  [dep1, dep2]  // ← dependency array
);

Dependency array controls WHEN the effect runs

Dependency arrayWhen does the effect run?
useEffect(fn) — no arrayAfter every render (avoid — usually wrong)
useEffect(fn, []) — empty arrayOnce, after the first render (like componentDidMount)
useEffect(fn, [a, b])After first render, and when a or b changes
// 1. Run once on mount — empty array
useEffect(() => {
  document.title = 'Web Programming Course';
}, []);

// 2. Run when userId changes — userId in dependencies
useEffect(() => {
  fetchUserProfile(userId);
}, [userId]);

// 3. Run after every render — no array (usually wrong!)
useEffect(() => {
  console.log('Rendered at:', new Date());
});
⚠️

Infinite loop trap: If your effect updates state, and that state is in the dependency array, you get an infinite loop. Always think: "does updating this state cause my effect to run again?"

3. Cleanup Functions

Some effects create resources that need to be released when the component unmounts or before the effect runs again (e.g., subscriptions, timers, event listeners). Return a cleanup function to handle this.

// Cleanup pattern — timer
function Countdown({ seconds }) {
  const [timeLeft, setTimeLeft] = useState(seconds);

  useEffect(() => {
    if (timeLeft === 0) return;

    const timerId = setInterval(() => {
      setTimeLeft(prev => prev - 1);
    }, 1000);

    // Cleanup: clear the timer when component unmounts
    // or before the next effect run
    return () => clearInterval(timerId);
  }, [timeLeft]);

  return <p>{timeLeft}s remaining</p>;
}

// Cleanup pattern — event listener
function WindowSize() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    const handleResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', handleResize);

    // Cleanup: remove listener when component unmounts
    return () => window.removeEventListener('resize', handleResize);
  }, []); // runs once — listener persists until cleanup

  return <p>Window width: {width}px</p>;
}
✅

Always cleanup: Forgetting to clear timers or remove event listeners causes memory leaks. When the component unmounts, React calls the cleanup function automatically.

4. Data Fetching Pattern

Fetching data from an API is the most common use of useEffect. The pattern: use state for data, isLoading, and error; fetch inside an effect with the right dependencies.

function CourseList({ instructorId }) {
  const [courses,   setCourses]   = useState([]);
  const [isLoading, setIsLoading] = useState(true);
  const [error,     setError]     = useState(null);

  useEffect(() => {
    setIsLoading(true);
    setError(null);

    fetch(`https://api.example.com/courses?instructor=${instructorId}`)
      .then(res => {
        if (!res.ok) throw new Error('Network error');
        return res.json();
      })
      .then(data => {
        setCourses(data);
        setIsLoading(false);
      })
      .catch(err => {
        setError(err.message);
        setIsLoading(false);
      });
  }, [instructorId]); // re-fetch when instructorId changes

  if (isLoading) return <p>Loading courses…</p>;
  if (error)     return <p style={{color:'red'}}>Error: {error}</p>;

  return (
    <ul>
      {courses.map(c => <li key={c.id}>{c.title}</li>)}
    </ul>
  );
}
💡

Async inside useEffect: You cannot make the useEffect callback itself async. Instead, define an async function inside the effect and call it immediately.

useEffect(() => {
  // Define async function inside
  async function loadCourses() {
    try {
      const res  = await fetch('/api/courses');
      const data = await res.json();
      setCourses(data);
    } catch (err) {
      setError(err.message);
    } finally {
      setIsLoading(false);
    }
  }

  loadCourses(); // call it immediately
}, []);

5. Common Patterns

Sync document title with state

useEffect(() => {
  document.title = `${unreadCount} unread messages — WebPro`;
}, [unreadCount]);

Debounced search (avoid fetching on every keystroke)

const [query, setQuery] = useState('');
const [results, setResults] = useState([]);

useEffect(() => {
  if (!query) { setResults([]); return; }

  const timerId = setTimeout(async () => {
    const res  = await fetch(`/api/search?q=${query}`);
    const data = await res.json();
    setResults(data);
  }, 400); // wait 400ms after typing stops

  return () => clearTimeout(timerId); // cancel if query changes quickly
}, [query]);

Practice Exercises

Exercise 1 — Page title sync

Task: Build a component with a text input. Use useEffect to update document.title to show whatever is typed in the input. Revert the title to "WebPro" when the component unmounts (via cleanup).

function TitleEditor() {
  const [text, setText] = useState('');

  useEffect(() => {
    document.title = text || 'WebPro';
    return () => { document.title = 'WebPro'; }; // cleanup on unmount
  }, [text]);

  return (
    <input
      value={text}
      onChange={e => setText(e.target.value)}
      placeholder="Type to change tab title…"
    />
  );
}
Exercise 2 — Fetch a user from an API

Task: Use https://jsonplaceholder.typicode.com/users/1 to fetch a user and display their name and email. Show "Loading…" while fetching and handle errors.

function UserProfile() {
  const [user, setUser]         = useState(null);
  const [loading, setLoading]   = useState(true);
  const [error, setError]       = useState(null);

  useEffect(() => {
    async function fetchUser() {
      try {
        const res  = await fetch('https://jsonplaceholder.typicode.com/users/1');
        if (!res.ok) throw new Error('Failed to fetch');
        const data = await res.json();
        setUser(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    }
    fetchUser();
  }, []); // empty array — run once on mount

  if (loading) return <p>Loading…</p>;
  if (error)   return <p>Error: {error}</p>;

  return (
    <div>
      <h2>{user.name}</h2>
      <p>{user.email}</p>
    </div>
  );
}
Exercise 3 — Stopwatch with cleanup

Task: Build a stopwatch with Start, Stop, and Reset buttons. Use setInterval inside useEffect and clean it up properly to avoid memory leaks.

function Stopwatch() {
  const [seconds, setSeconds] = useState(0);
  const [running, setRunning] = useState(false);

  useEffect(() => {
    if (!running) return; // do nothing when stopped

    const id = setInterval(() => setSeconds(s => s + 1), 1000);
    return () => clearInterval(id); // cleanup when running changes or unmounts
  }, [running]);

  return (
    <div>
      <p>{seconds}s</p>
      <button onClick={() => setRunning(true)}>Start</button>
      <button onClick={() => setRunning(false)}>Stop</button>
      <button onClick={() => { setRunning(false); setSeconds(0); }}>Reset</button>
    </div>
  );
}

🔄 useEffect — Cheat Sheet

Run once (on mount)

useEffect(() => {
  // setup
}, []);

Run on dep change

useEffect(() => {
  fetchData(id);
}, [id]);

With cleanup

useEffect(() => {
  const id = setInterval(fn, 1000);
  return () => clearInterval(id);
}, []);

Async data fetch

useEffect(() => {
  async function load() {
    const d = await fetch(url).then(r=>r.json());
    setData(d);
  }
  load();
}, [url]);

Loading pattern

const [data, setData] = useState(null);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);

Dep array rules

[]    → once on mount
[a]   → on a change
none  → every render (avoid)

Avoid infinite loop

// ❌ state in deps that effect updates
useEffect(()=>{ setX(1); }, [x]);
// ✅ no dep, or functional form

No async callback

// ❌ useEffect(async () => {...});
// ✅ define async fn inside, call it
