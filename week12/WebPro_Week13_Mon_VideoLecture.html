⚖️ Controlled vs Uncontrolled

Uncontrolled Input
  • DOM manages the value
  • Read value with ref.current.value
  • Simpler — less code
  • Hard to validate in real-time
  • Hard to reset programmatically
<input defaultValue="initial" />
Controlled Input (React way)
  • React state manages the value
  • Read value from state
  • More code — more power
  • Real-time validation easy
  • Reset by setting state to ""
<input value={name} onChange={...} />
Use controlled inputs in React for most cases. Uncontrolled inputs are only needed for file inputs or third-party DOM libraries.

🎛️ The Controlled Input Pattern

Three things make an input "controlled": value from state, onChange that updates state, and state initialized to a string.

import { useState } from 'react';

function NameInput() {
  const [name, setName] = useState(''); // must be string, not null/undefined

  return (
    <div>
      <label htmlFor="name">이름</label>
      <input
        id="name"
        type="text"
        value={name}            // ← controlled by state
        onChange={e => setName(e.target.value)} // ← updates state
        placeholder="이름을 입력하세요"
      />
      <p>입력: {name || '(없음)'}</p>
      <button onClick={() => setName('')}>지우기</button>
    </div>
  );
}

🎯 Multiple Inputs — One Handler

Use e.target.name to handle multiple inputs with a single onChange handler.

function RegistrationForm() {
  const [form, setForm] = useState({
    name: '', email: '', studentId: '',
  });

  const handleChange = (e) => {
    const { name, value } = e.target; // name attribute of the input
    setForm(prev => ({ ...prev, [name]: value }));
  };

  return (
    <form>
      <input name="name"      value={form.name}      onChange={handleChange} />
      <input name="email"     value={form.email}     onChange={handleChange} />
      <input name="studentId" value={form.studentId} onChange={handleChange} />
    </form>
  );
}
The name attribute on the HTML <input> must match the key in your state object.

🚀 Form Submission

Always call e.preventDefault() in onSubmit to stop the browser from reloading the page.

function LoginForm() {
  const [form, setForm] = useState({ email: '', password: '' });
  const [status, setStatus] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault(); // ← prevents page reload
    setStatus('로그인 중...');
    // POST to API
    fetch('/api/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(form),
    }).then(res => {
      if (res.ok) setStatus('✅ 로그인 성공!');
      else setStatus('❌ 이메일 또는 비밀번호가 틀렸습니다.');
    });
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="email" type="email" value={form.email}
             onChange={e => setForm(p => ({...p, email: e.target.value}))} />
      <button type="submit">로그인</button>
      {status && <p>{status}</p>}
    </form>
  );
}

✅ Client-Side Validation

function SignupForm() {
  const [form, setForm] = useState({ name: '', email: '', password: '' });
  const [errors, setErrors] = useState({});

  const validate = () => {
    const e = {};
    if (!form.name.trim())         e.name = '이름을 입력하세요.';
    if (!form.email.includes('@')) e.email = '유효한 이메일을 입력하세요.';
    if (form.password.length < 8)  e.password = '비밀번호는 최소 8자입니다.';
    return e;
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    const errs = validate();
    if (Object.keys(errs).length) { setErrors(errs); return; }
    // no errors — proceed with submission
    setErrors({});
    console.log('Submitting:', form);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" value={form.name}
        onChange={e => setForm(p=>({...p,name:e.target.value}))} />
      {errors.name && <span className="error">{errors.name}</span>}
      <button type="submit">가입</button>
    </form>
  );
}

☑️ Checkboxes & Radio Buttons

function PreferencesForm() {
  const [agreed, setAgreed]   = useState(false);
  const [gender, setGender]   = useState('');
  const [skills, setSkills]   = useState([]);

  const toggleSkill = (skill) => {
    setSkills(prev =>
      prev.includes(skill)
        ? prev.filter(s => s !== skill)
        : [...prev, skill]
    );
  };

  return (
    <form>
      // Checkbox — controlled by boolean
      <input type="checkbox" checked={agreed}
             onChange={e => setAgreed(e.target.checked)} />
      <label>약관에 동의합니다</label>

      // Radio buttons — controlled by string
      {['남성', '여성', '기타'].map(g => (
        <label key={g}>
          <input type="radio" value={g} checked={gender===g}
                 onChange={() => setGender(g)} /> {g}
        </label>
      ))}

      // Multi-select checkboxes — controlled by array
      {['HTML','CSS','React'].map(s => (
        <label key={s}>
          <input type="checkbox" checked={skills.includes(s)}
                 onChange={() => toggleSkill(s)} /> {s}
        </label>
      ))}
    </form>
  );
}

📋 Select Dropdowns & Textarea

function CourseForm() {
  const [dept, setDept]       = useState('computer');
  const [comment, setComment] = useState('');

  return (
    <form>
      // Select dropdown — value on <select>, not <option>
      <label htmlFor="dept">학과</label>
      <select id="dept" value={dept} onChange={e => setDept(e.target.value)}>
        <option value="computer">컴퓨터공학과</option>
        <option value="software">소프트웨어학과</option>
        <option value="ai">AI학과</option>
      </select>

      // Textarea — also uses value + onChange
      <label htmlFor="comment">강의 평가</label>
      <textarea
        id="comment"
        value={comment}
        onChange={e => setComment(e.target.value)}
        rows={5}
        placeholder="수업에 대한 의견을 적어주세요..."
      />
      <p>{comment.length}/500자</p>
    </form>
  );
}

🔗 useRef for Uncontrolled Inputs

Use useRef when you need to access a DOM element directly — for example, to focus an input or read a file input.

import { useRef, useEffect } from 'react';

function AutoFocusSearch() {
  const inputRef = useRef(null);

  // Focus the input automatically on mount
  useEffect(() => {
    inputRef.current.focus();
  }, []);

  const handleSubmit = () => {
    // Read value directly from DOM (uncontrolled)
    console.log(inputRef.current.value);
  };

  return (
    <div>
      <input ref={inputRef} type="search"
             defaultValue="" placeholder="검색..." />
      <button onClick={handleSubmit}>검색</button>
    </div>
  );
}
useRef does NOT cause re-renders when its value changes — that's the key difference from useState.

🏆 Full Registration Form Example

function StudentRegForm() {
  const [form, setForm] = useState({ name:'',studentId:'',dept:'cs',agreed:false });
  const [errors, setErrors] = useState({});
  const [submitted, setSubmitted] = useState(false);

  const change = (e) => {
    const { name, value, type, checked } = e.target;
    setForm(p => ({ ...p, [name]: type==='checkbox' ? checked : value }));
  };

  const submit = (e) => {
    e.preventDefault();
    const errs = {};
    if (!form.name.trim()) errs.name = '이름 필수';
    if (!/^\d{8}$/.test(form.studentId)) errs.studentId = '8자리 학번';
    if (!form.agreed) errs.agreed = '동의 필요';
    setErrors(errs);
    if (!Object.keys(errs).length) setSubmitted(true);
  };

  if (submitted) return <h2>{form.name}님, 등록 완료!</h2>;

  return (
    <form onSubmit={submit}>
      <input name="name" value={form.name} onChange={change} placeholder="이름"/>
      {errors.name && <span>{errors.name}</span>}
      <input name="studentId" value={form.studentId} onChange={change} placeholder="학번(8자리)"/>
      {errors.studentId && <span>{errors.studentId}</span>}
      <select name="dept" value={form.dept} onChange={change}>
        <option value="cs">컴퓨터공학</option>
        <option value="sw">소프트웨어</option>
      </select>
      <input type="checkbox" name="agreed" checked={form.agreed} onChange={change}/> 약관동의
      {errors.agreed && <span>{errors.agreed}</span>}
      <button type="submit">등록</button>
    </form>
  );
}

⚠️ Common Mistakes

❌ Uninitialized state (causes "uncontrolled to controlled" warning)
const [name, setName] = useState(null); // Wrong — use '' not null
<input value={name} .../> // React warns: switching to controlled!
❌ Missing e.preventDefault() on submit
const handleSubmit = () => { // no e parameter!
  // Page reloads before you can do anything
};
✅ Correct initialisation
const [name, setName] = useState(''); // empty string ✓
const [count, setCount] = useState(0); // number ✓
const [checked, setChecked] = useState(false); // boolean ✓

🔄 Real-time Validation Pattern

function EmailInput() {
  const [email, setEmail]   = useState('');
  const [touched, setTouched] = useState(false);

  const isValid = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
  const showError = touched && !isValid;

  return (
    <div>
      <input
        type="email"
        value={email}
        onChange={e => setEmail(e.target.value)}
        onBlur={() => setTouched(true)}  // only show error after user leaves
        style={{ borderColor: showError ? 'red' : 'inherit' }}
      />
      {showError && <p style={{color:'red'}}>유효한 이메일을 입력하세요.</p>}
      {isValid && <p style={{color:'green'}}>✓ 유효한 이메일</p>}
    </div>
  );
}
Use the onBlur event to show validation only after the user has left the field — not while still typing.

✅ Summary — Key Takeaways

1
Controlled inputs: bind value to state and update state in onChange. Never let state be null/undefined.
2
One handler for many inputs: use e.target.name + computed property [name]: value.
3
Form submission: always e.preventDefault() first.
4
Validation: validate on submit, set an errors object, show per-field messages.
5
Checkboxes: use checked + e.target.checked. Multi-select = array in state.
6
Select & Textarea: same pattern — value on the element + onChange.
7
useRef: for DOM focus, file inputs, or third-party DOM integrations. No re-render on change.
