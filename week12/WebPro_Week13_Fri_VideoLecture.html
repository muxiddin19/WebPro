🌍 Client-Side Routing

Traditional websites: clicking a link sends a request to the server, the server returns a whole new HTML page. With React, we build Single Page Applications (SPAs) — the page never fully reloads.

Traditional routing
  • Browser → Server: GET /about
  • Server → Browser: 200 OK + full HTML page
  • Visible: white flash, full page reload
Client-side routing (SPA)
  • JavaScript intercepts the link click
  • Updates the URL bar using History API
  • Swaps React components without network request
  • Instant navigation — no white flash
React Router is the most popular library for client-side routing in React apps.

import { BrowserRouter } from 'react-router-dom';

ReactDOM.createRoot(document.getElementById('root')).render(

BrowserRouter must wrap your entire app — usually at the entry point, not inside components.

🗺️ Routes and Route

Define which component to show for each URL path using <Routes> and <Route>.

import { Routes, Route } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';
import Courses from './pages/Courses';
import NotFound from './pages/NotFound';

function App() {
  return (
    <div>
      <Navbar />         // always visible
      <Routes>
        <Route path="/"        element={<Home />} />
        <Route path="/about"   element={<About />} />
        <Route path="/courses" element={<Courses />} />
        <Route path="*"        element={<NotFound />} />  // 404
      </Routes>
      <Footer />         // always visible
    </div>
  );
}

🔗 Link vs <a>

Always use <Link> from React Router instead of <a href> — it prevents full page reloads.

import { Link, NavLink } from 'react-router-dom';

function Navbar() {
  return (
    <nav>
      // NavLink adds an "active" class when path matches
      <NavLink to="/"        className={({ isActive }) => isActive ? 'active' : ''}>홈</NavLink>
      <NavLink to="/courses" className={({ isActive }) => isActive ? 'active' : ''}>강좌</NavLink>
      <NavLink to="/about"   className={({ isActive }) => isActive ? 'active' : ''}>소개</NavLink>

      // Plain Link — no active styling
      <Link to="/login">로그인</Link>
    </nav>
  );
}
NavLink is Link + automatic active class. Use it for navigation menus. Use plain Link for other links.

⚡ useNavigate — Programmatic Navigation

Navigate without a click — after form submission, login success, or any event.

import { useNavigate } from 'react-router-dom';

function LoginForm() {
  const navigate = useNavigate();
  const [creds, setCreds] = useState({ email: '', password: '' });

  const handleSubmit = async (e) => {
    e.preventDefault();
    const ok = await login(creds.email, creds.password);
    if (ok) {
      navigate('/dashboard');         // go forward
    } else {
      navigate('/login?error=1');      // go to same page with query
    }
  };

  return <form onSubmit={handleSubmit}>...</form>;
}

// Go back one page in history
navigate(-1);

// Replace current history entry (no back button)
navigate('/home', { replace: true });

🏷️ useParams — URL Parameters

Extract dynamic values from the URL path.

// Route definition — :courseId is the parameter
<Route path="/courses/:courseId" element={<CourseDetail />} />

// CourseDetail.jsx
import { useParams } from 'react-router-dom';

function CourseDetail() {
  const { courseId } = useParams();

  const [course, setCourse] = useState(null);

  useEffect(() => {
    fetch(`/api/courses/${courseId}`)
      .then(r => r.json())
      .then(setCourse);
  }, [courseId]);

  if (!course) return <p>로딩 중...</p>;
  return <h1>{course.title}</h1>;
}

// URL: /courses/web-programming-101
// courseId = "web-programming-101"

🌲 Nested Routes & Outlet

Nest routes to build layouts where only part of the page changes.

// App.jsx — parent route with Layout
<Routes>
  <Route path="/courses" element={<CoursesLayout />}>
    <Route index element={<CoursesList />} />
    <Route path=":courseId" element={<CourseDetail />} />
    <Route path=":courseId/enroll" element={<EnrollForm />} />
  </Route>
</Routes>

// CoursesLayout.jsx — Outlet renders the matched child route
import { Outlet, NavLink } from 'react-router-dom';

function CoursesLayout() {
  return (
    <div className="courses-layout">
      <aside>
        <h3>강좌 목록</h3>
        <NavLink to="/courses" end>전체 강좌</NavLink>
      </aside>
      <main>
        <Outlet />  // ← child route renders here
      </main>
    </div>
  );
}

🔍 Query Strings with useSearchParams

import { useSearchParams } from 'react-router-dom';

function CourseSearch() {
  const [searchParams, setSearchParams] = useSearchParams();
  const query = searchParams.get('q') || '';

  const handleSearch = (e) => {
    setSearchParams({ q: e.target.value });
    // URL becomes: /courses?q=React
  };

  return (
    <div>
      <input
        value={query}
        onChange={handleSearch}
        placeholder="강좌 검색..."
      />
      {query && <p>"{query}" 검색 결과:</p>}
    </div>
  );
}
URL: /courses?q=React — the search is shareable and bookmarkable!

⚠️ Common Mistakes

❌ Using <a href> instead of <Link>
<a href="/about">소개</a>  // Full page reload!
<Link to="/about">소개</Link>  // SPA navigation ✓
❌ Routes outside BrowserRouter
// WRONG — no BrowserRouter wrapping
<App/>  // Error: useNavigate() may be used only in a Router
❌ Not using index route
// No "index" — /courses doesn't render anything!
<Route path="/courses" element={<Layout/>}>
  <Route path=":id" element={<Detail/>}/>
  // Missing: <Route index element={<List/>}/>
</Route>

🔒 Protected Routes Pattern

function ProtectedRoute({ children }) {
  const { isLoggedIn } = useAuth(); // custom hook
  const location = useLocation();

  if (!isLoggedIn) {
    // Redirect to login, remember where they were trying to go
    return <Navigate to="/login"
                      state={{ from: location }} replace />;
  }

  return children;
}

// In routes:
<Route
  path="/dashboard"
  element={
    <ProtectedRoute>
      <Dashboard />
    </ProtectedRoute>
  }
/>
This pattern is very common in real apps — wrap sensitive routes in a ProtectedRoute component that checks auth status.

✅ Summary — Key Takeaways

1
Client-side routing: React Router intercepts navigation, swaps components, updates URL — no full reload.
2
BrowserRouter at the top, Routes + Route inside App to define the routing table.
3
Use Link/NavLink instead of <a href> — prevents page reloads.
4
useNavigate() for programmatic navigation (after form submit, login, etc.)
5
useParams() reads dynamic segments from the URL path (/courses/:id → id).
6
Nested routes: parent renders <Outlet />, child routes render inside it.
7
path="*" is the catch-all 404 route — always list it last.
