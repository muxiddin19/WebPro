# Web Programming

A shared course repository for the Web Programming course taught jointly at:

- **Gachon University** (Department of Computer Engineering)
- **Jizzakh Branch, National University of Uzbekistan**

Instructor: **Dr. Mukhiddin Toshpulatov**

This repository holds all lecture materials, example code, and reference
resources for both cohorts. Everything is organized as a single folder tree so
students at either campus can clone the same repo and follow along with the
same materials.

**Course page:** https://muxiddin19.github.io/WebPro/

---

## Repository structure

| Folder | Contents |
|---|---|
| `/LectureNotes` | Weekly slides and written lecture notes |
| `/SourceCodes` | Example code and demos built during class |
| `/UsefullResources` | Tools, references, and cheat sheets |
| `/Videos` | Recorded lecture sessions and demos |
| `/Images` | Diagrams and screenshots used in class |
| `/MyDAta` | Sample datasets used in assignments |
| `/docs` | Source for the GitHub Pages course site |

## Course overview

This course covers the foundations of building for the web:

- HTML, CSS, and JavaScript fundamentals
- DOM manipulation and browser APIs
- Client-server interaction and HTTP
- Working with external APIs and data
- Modern front-end practices

## Getting started

Clone the repository to follow along locally:

```bash
git clone https://github.com/muxiddin19/WebPro.git
cd WebPro
```

Lecture notes and code examples are added as the course progresses — pull the
latest changes regularly:

```bash
git pull origin main
```
